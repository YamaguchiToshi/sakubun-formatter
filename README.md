# 原稿用紙フォーマッター (Sakubun Formatter)

入力したテキストを、日本の伝統的な400字詰め原稿用紙（縦書き・20字×20行）のレイアウトに自動変換し、ブラウザ上で美しく表示・印刷・PDF保存ができるWebアプリケーションです。

大学入試や小論文の厳格な組版ルール（追い出し禁則・1マス1文字の原則など）に完全対応するようにゼロから設計された独自の文字列解析（トークナイザー）エンジンを搭載しています。

## ✨ 主な機能と特徴

### 1. 厳格な組版ルール（大学入試・小論文対応）
- **完全1マス1文字**: 「ぶら下がり」を使用せず、句読点（。、）や英数字などのあらゆる文字が完全に1つのマスに収まります。
- **自動インデント**: 段落（改行）の先頭には、自動的に全角スペース（1マスの空白）が挿入されます。
- **追い出し（Oidashi）禁則処理**:
  - **行頭禁則**: `。` `、` `」` `！` などの記号が行の先頭に来ることを防ぎます。該当する場合、直前の文字ごとセットで次の行の先頭に押し出します。
  - **行末禁則**: `「` `（` などの開き括弧が行の末尾に来る場合、括弧ごと次の行へ押し出します。

### 2. インテリジェントな英単語・数値ラップ
- `information` のような英単語や、`2025`、`30%` などの数値と単位の組み合わせを「意味のある1つの塊（トークン）」として解析します。
- 行の途中で単語が途切れて次の行にまたがってしまう（ハイフネーションのような状態）を防ぐため、単語全体が収まらない場合は**単語の塊ごと次の行へ自動で送られます**（英数字の分断禁止ルール）。
- 縦書きグリッド内に配置される英字・半角数字は、横倒しにならずに正立するよう設計されています（`text-orientation: upright`）。

### 3. ダークモード対応
- 画面右上のアイコン（🌙 / ☀️）をクリックすることで、目に優しいダークモードと標準モードを瞬時に切り替えられます。
- ユーザーの選択設定はブラウザ（`localStorage`）に記憶され、次回アクセス時も維持されます。
- 初回アクセス時はOSの設定（`prefers-color-scheme`）に連動します。

### 4. 印刷・PDF保存の最適化 (`@media print`)
- A4サイズの横向き（Landscape）に最適化された印刷用CSSを搭載しています。
- **インク節約設計**: 画面上でダークモードを選択していても、印刷ボタン（またはブラウザの標準印刷）を押した際は**自動的に白背景・黒文字（ライトモード）に切り替わり**、本物の原稿用紙と同じように出力・PDF保存が可能です。

### 5. アプリケーション化（PWA / ホーム画面に追加）
- `manifest.json` と `apple-touch-icon` を完備しており、プログレッシブWebアプリ（PWA）として動作します。
- iPadやiPhoneのSafariなどのブラウザから「ホーム画面に追加」を実行することで、アドレスバーの無い全画面のネイティブアプリ感覚で執筆作業が行なえます。専用の鉛筆アイコンも設定済みです。

## 🛠️ 技術スタック
ReactやVueなどの外部フレームワークを使用せず、Vanilla（純粋な）技術のみで軽量に構築されています。
- HTML5
- CSS3 (Flexbox縦書きレイアウト, CSS Variables)
- Vanilla JavaScript

## 📁 内部構造 (Core Logic)
`script.js` 内のエンジンは主に2つのステップで動作します：
1. **`tokenize(text)`**: 入力された長文文字列を舐め、1文字の漢字やひらがな、複数の文字から成る「英単語」「数値＋単位」、そして「改行」というトークンの配列に分割します。
2. **`processText(text)`**: 得られたトークン配列をループ処理し、各行（20マス）の残りマス数を計算しながら、上記の「追い出し禁則」や「単語分断ルール」に違反しないよう、必要に応じて空白マス（`null`）を挿入して文字を次の列に流し込みます。文字データを含んだ配列が完成した後、DOM（マス目のdiv要素）としてレンダリングされます。

## 📝 開発・起動方法
ローカル環境で実行する場合は、プロジェクトのルートディレクトリで任意の静的Webサーバーを立ち上げるだけで動作します。

```bash
# Pythonがインストールされている場合
python3 -m http.server 8585
# その後、ブラウザで http://localhost:8585 にアクセスしてください
```
